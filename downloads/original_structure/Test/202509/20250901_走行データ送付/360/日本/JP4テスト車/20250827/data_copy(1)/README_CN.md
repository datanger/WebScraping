# 数据拷贝工具使用说明 (中文版)

## 📋 工具概述

数据拷贝工具是一个专为Qdrive和Vector数据管理设计的自动化拷贝工具，支持多驱动器并行拷贝、自动驱动器识别和完整的日志记录功能。

## 🚀 主要功能

### 自动驱动器识别
- **Qdrive 201**: 自动识别包含 `camera_fc*.mp4` 文件的驱动器
- **Qdrive 203**: 自动识别包含 `camera_rc*.mp4` 文件的驱动器  
- **Qdrive 230**: 自动识别包含 `data_lidar_top` 文件夹的驱动器
- **Qdrive 231**: 自动识别包含 `data_lidar_front` 文件夹的驱动器
- **Vector**: 自动识别包含 `logs` 文件夹的驱动器
- **Transfer**: 自动识别卷名以 "Echo" 开头但不以 "backup" 结尾的驱动器
- **Backup**: 自动识别卷名以 "Echo" 开头且以 "backup" 结尾的驱动器

### 高性能拷贝
- **多线程并行拷贝**: 根据CPU核心数自动优化线程数
- **智能缓冲区**: 32KB缓冲区大小，提升拷贝效率
- **实时进度显示**: 清晰的进度条和文件计数显示

### 完整日志记录
- **拷贝日志**: 记录所有拷贝操作的详细信息
- **文件列表**: 记录源驱动器的完整文件结构
- **时间戳**: 所有操作都有精确的时间记录

## 🔄 使用流程

### 1. 启动程序
程序启动后会自动：
- 检测所有外部驱动器
- 检查BitLocker状态
- 自动识别Qdrive、Vector、Transfer和Backup驱动器

### 2. 确认驱动器识别
程序会显示识别结果，包括：
- 驱动器路径和卷名
- 文件夹结构分析
- 识别原因说明

确认识别正确后选择 `Y` 继续。

### 3. 检查Vector数据日期
程序会检查Vector驱动器中的数据日期，确保数据一致性。

### 4. 选择拷贝计划
程序提供以下拷贝选项：
- **Transfer驱动器拷贝**: 将Qdrive和Vector数据拷贝到Transfer驱动器
- **Backup驱动器拷贝**: 将Qdrive和Vector数据拷贝到Backup驱动器

### 5. 执行拷贝
- 程序使用高性能模式自动执行拷贝
- 显示实时进度条和文件计数
- 所有操作记录到日志文件

## ⚙️ 配置选项

### 高性能模式配置
- **8核以上CPU**: 6个并行线程
- **4-7核CPU**: 4个并行线程
- **4核以下**: 2个并行线程
- **缓冲区大小**: 32KB

### 进度显示
- 实时进度条显示
- 文件计数统计
- 状态图标指示

## 🔧 故障排除

### 常见问题

**1. 驱动器无法识别**
- 检查驱动器是否已正确连接
- 确认驱动器包含预期的文件结构
- 检查驱动器权限

**2. BitLocker加密驱动器**
- 程序会自动检测BitLocker状态
- 需要手动解锁加密驱动器

**3. 权限不足**
- 以管理员身份运行程序
- 检查目标驱动器的写入权限

**4. 空间不足**
- 检查目标驱动器的可用空间
- 清理不需要的文件

### 错误代码
- **权限错误**: 检查驱动器访问权限
- **空间不足**: 清理目标驱动器空间
- **文件锁定**: 关闭可能占用文件的程序
